**RapidRAW [{{UPSTREAM_TAG}}](https://github.com/CyberTimon/RapidRAW/releases/tag/{{UPSTREAM_TAG}})**, unmodified, served to your browser from a machine on your network. See the RapidRAW release for what's new in the editor itself.

### Downloads
On the server you need **one bridge package + the server bundle**:
- **Server bundle** `rapidraw-web-server-*.tar.gz` / `.zip`: the RapidRAW UI built for the browser, the relay and start scripts (needs Node.js 20+).
- **Bridge**: RapidRAW in bridge mode, does all processing on the server's GPU:
  - Linux x86_64 / aarch64: `.deb` (Debian/Ubuntu), `.rpm` (Fedora/openSUSE), `.AppImage` (any distro)
  - Windows x64: NSIS installer (experimental)

Setup: [README → Quick start](https://github.com/vedranius/rapidraw-web#quick-start)

### Known limitations
One active editing session at a time · Open/Save dialogs are a path prompt · desktop-only window features and tethering are not available · Windows build is untested.
